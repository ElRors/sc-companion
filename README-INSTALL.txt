STARCITIZEN COMPANION
=====================

Lo que contiene / Contents
  StarCitizen-Companion.apk      -> App para la tablet Android / Android tablet app
  SC-Companion-Setup.exe         -> Servidor para el PC con Windows / Windows PC server


ESPAÑOL
-------
Requisitos: PC con Windows y Star Citizen, y una tablet Android. Ambos deben estar en la MISMA red wifi.

PASO 1 - Instalar el servidor en el PC
  1. Ejecuta SC-Companion-Setup.exe.
     Si Windows muestra "Windows protegió su PC", pulsa "Más información" y luego "Ejecutar de todas formas".
  2. Escribe un token (una contraseña corta que tú elijas) y pulsa instalar.
  3. Se crea el acceso directo "SC Companion Server" en el escritorio.

PASO 2 - Iniciar el servidor (cada vez que juegues)
  1. Abre "SC Companion Server" desde el escritorio (pide permisos de administrador: acepta).
  2. Verás una ventana con la IP:puerto del PC (por ejemplo 192.168.1.4:8765) y tu token.
  3. Pulsa "Guardar e iniciar" y deja la ventana abierta mientras juegas.
  Si el firewall de Windows pregunta, permite el acceso en redes privadas.

PASO 3 - Instalar la app en la tablet
  1. Copia StarCitizen-Companion.apk a la tablet (cable, Drive, WhatsApp...).
  2. Ábrelo y acepta "Instalar apps de origen desconocido" cuando Android lo pida.
  3. Si Play Protect avisa, pulsa "Instalar de todas formas".

PASO 4 - Conectar la app con el PC
  1. Abre la app y toca la rueda de ajustes (arriba a la derecha).
  2. Escribe la IP:puerto que muestra el servidor y el mismo token.
  3. Pulsa "Probar": debe decir "Conectado". Luego "Guardar".
  4. El icono de wifi arriba a la derecha se pone verde cuando hay conexión.
  5. Para cambiar a inglés, usa el selector Español / English en esos mismos ajustes.

USO
  - El juego debe estar en primer plano en el PC. La app envía las teclas como si las pulsaras.
  - Si una tecla no coincide con tus atajos del juego, mantén pulsado el botón para cambiarla.

PROBLEMAS FRECUENTES
  - "Sin conexión": comprueba que el servidor esté iniciado, que la IP sea la actual
    (puede cambiar al reiniciar el router) y que ambos equipos estén en la misma wifi.
  - Una tecla no responde en el juego: el servidor debe ejecutarse como administrador.
  - Tras actualizar el servidor, cierra el anterior (icono de la bandeja o Administrador de tareas) antes de abrir el nuevo.


ENGLISH
-------
Requirements: a Windows PC with Star Citizen and an Android tablet, both on the SAME wifi network.

STEP 1 - Install the server on the PC
  1. Run SC-Companion-Setup.exe.
     If Windows shows "Windows protected your PC", click "More info" then "Run anyway".
  2. Type a token (a short password of your choice) and click install.
  3. A "SC Companion Server" shortcut is created on the desktop.

STEP 2 - Start the server (every time you play)
  1. Open "SC Companion Server" from the desktop (it asks for administrator rights: accept).
  2. A window shows the PC's IP:port (e.g. 192.168.1.4:8765) and your token.
  3. Click "Guardar e iniciar" (Save and start) and keep the window open while you play.
  If Windows Firewall asks, allow access on private networks.

STEP 3 - Install the app on the tablet
  1. Copy StarCitizen-Companion.apk to the tablet (cable, Drive, WhatsApp...).
  2. Open it and allow "Install unknown apps" when Android asks.
  3. If Play Protect warns, tap "Install anyway".

STEP 4 - Connect the app to the PC
  1. Open the app and tap the settings gear (top right).
  2. Enter the IP:port shown by the server and the same token.
  3. Tap "Test": it should say "Connected". Then "Save".
  4. The wifi icon at the top right turns green when connected.
  5. To switch language, use the Español / English selector in the same settings.

USAGE
  - The game must be in the foreground on the PC. The app sends keys as if you pressed them.
  - If a key does not match your in-game keybinds, long-press the button to change it.

TROUBLESHOOTING
  - "No connection": make sure the server is started, the IP is current
    (it may change when the router restarts) and both devices are on the same wifi.
  - A key does nothing in game: the server must run as administrator.
  - After updating the server, close the old one (Task Manager) before opening the new one.
